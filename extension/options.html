Summarizing and answering run on this machine, with no key and no quota. Semantic search in this mode matches on shared vocabulary rather than a learned model — weaker than a cloud embedding, but it works offline and nothing is sent anywhere.

Reminders from conversations

On sites you turn this on for, mem watches messages for a time plus an obligation — "the report is due Friday at 3pm" — and offers to remind you. Detection happens entirely on this device with no model call, and nothing is sent anywhere unless you accept the reminder.

Off everywhere by default. This reads the messages on the page it runs on, so add only the sites you want it on. It works on any messaging platform — Discord, Slack, WhatsApp Web, Teams, Messenger, a forum, anything.

Anywhere else, select text and choose Remind me about this… from the right-click menu — that works on every site with nothing turned on.

Background deepening

The first-run scan indexes thousands of pages by title alone. Those can be found but not answered from. Deepening quietly re-fetches the ones you actually cared about — pages you returned to, bookmarked, or read recently — and summarizes them properly.

One-time setup (~5 min, only if Connect fails)

Full step-by-step walkthrough with every click is in mem/SETUP_GOOGLE.md. Short version:

  1. Open chrome://extensions, copy this extension's ID.
  2. Go to console.cloud.google.com → create a project → enable the Drive / Gmail / YouTube Data v3 / Calendar APIs.
  3. OAuth consent screen (or Google Auth Platform → Branding): pick External, fill in app name + your email. Under Scopes, add the four .readonly scopes. Under Test users, add your own Gmail.
  4. Credentials → + Create credentials → OAuth client ID → type Chrome extension. Item ID = the extension ID from step 1.
  5. Copy the resulting ...apps.googleusercontent.com string. Paste it into extension/manifest.json replacing YOUR_GOOGLE_OAUTH_CLIENT_ID. Reload the extension.

Why this can't be zero-setup: Chrome ties each OAuth client to a specific extension ID, and unpacked extensions have a per-machine ID. So someone has to pair them, and that has to be you, once per machine.
